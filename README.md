# Sistema de Tarefas - Banco de Dados

Este projeto é um sistema simples de gerenciamento de tarefas, com foco na modelagem e manipulação de banco de dados SQL, utilizando controle de versão com Git.

## 📦 Estrutura do Projeto

- `schema.sql`: criação das tabelas `Usuario` e `Tarefa`.
- `dados-exemplo.sql`: inserção de dados de exemplo.
- `consultas.sql`: consultas SQL úteis.
- `README.md`: documentação do projeto.

## 🔄 Funcionalidades

- Inserção de usuários e tarefas
- Relacionamento 1:N entre usuários e tarefas
- Consultas por usuário, status e relacionamento

## 🚀 Tecnologias Utilizadas

- SQL (PostgreSQL ou outro SGBD compatível)
- Git e GitHub

## 📚 Objetivo Educacional

Este projeto foi desenvolvido como parte do **Módulo 3** da disciplina de Banco de Dados e visa integrar:
- Modelagem de dados
- Manipulação com SQL
- Controle de versão com Git
